# Security Policy

## Supported versions

Only the latest tagged release is supported with security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue containing credentials, provider sessions, private URLs, camera
identifiers or Home Assistant diagnostics.

Include the affected version, a minimal reproduction and the expected security
boundary. Replace every account, token, serial and network address with a
synthetic value before attaching logs.
